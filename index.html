A BASE DE TUDO

Três camadas.
Uma experiência.

Cada tecnologia tem uma função. Juntas, elas dão forma à página.

01 / ESTRUTURA E ESTILO

HTML + CSS

O HTML organiza o conteúdo: títulos, parágrafos, links e formulários.

O CSS define a aparência: cores, fontes, espaços e organização dos elementos na tela.

Neste projeto: o HTML cria o título e o CSS deixa uma parte dele verde.

02 / COMPORTAMENTO

JavaScript

O JavaScript permite que a página responda às ações de quem a utiliza.

Aqui, ele verifica os campos do formulário. Se houver um erro, mostra uma explicação; se os dados forem válidos, abre o agradecimento.

Experimente preencher o formulário abaixo para ver esse comportamento.
