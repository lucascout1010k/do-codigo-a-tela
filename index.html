A BASE DE TUDO

Três camadas.
Uma experiência.

Uma página web combina diferentes tecnologias. Cada uma tem uma função — juntas, transformam informação em interação.

ESTRUTURA + IDENTIDADE

HTML e CSS: conteúdo com forma.

HTML organiza o que existe na página: títulos, parágrafos, links, imagens e formulários.

CSS define como esse conteúdo aparece: cores, fontes, espaços e organização na tela.

COMPORTAMENTO + INTERAÇÃO

JavaScript: a página responde.

JavaScript executa ações quando alguém interage com a página, como rolar a tela ou enviar um formulário.

Aqui, ele controla as cenas da narrativa e confere os campos do contato antes de abrir a página de agradecimento.

TECNOLOGIA FUNÇÃO EXEMPLO
01</> HTML Define a estrutura e organiza o conteúdo. <h1>Título</h1>
02✳ CSS Controla aparência, layout, cores e animações. color: #ffffff;
03JS JavaScript Adiciona lógica e comportamentos interativos. addEventListener()

FIM DA EXPERIÊNCIA 04 / 04

O código constrói.
A experiência conecta.

Uma boa página não é apenas o que vemos na tela. É a combinação entre estrutura, estilo e a forma como as pessoas interagem com ela.
